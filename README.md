After four billion wishes a night with not a single good night wished back, the Moon finally files its complaint: it is not a vending machine, just a rock with insomnia and excellent lighting, tired of granting wishes for strangers who never once asked how its night was going.

## How to run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` with no trailing newline. For a local scratch run, set `OUTPUT_DIR` to a directory of your choice, e.g. `OUTPUT_DIR=/tmp/moon25-a python3 main.py`.
